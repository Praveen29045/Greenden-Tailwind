GreenDen — Plant Store Website

A responsive plant store website inspired by GreenDen, built with **HTML** and **Tailwind CSS**. The site includes a home page, a products page, and a contact page.

## Pages

- **Home** — introduces the store and its plant collection.
- **Products** — showcases plants and products.
- **Contact** — provides a way for visitors to get in touch.

## Built With

- HTML
- Tailwind CSS

## Responsive Design

The layouts are designed to adapt across mobile, tablet, and desktop screen sizes.
